# Bank Account Withdrawal — Improvement Exercise

A take-home exercise for the **Sanlam Fintech** software engineering role: improve a provided
Spring Boot code snippet that performs a bank-account withdrawal and publishes a withdrawal event,
**while preserving the existing business behaviour**.

## The brief

> Improve on the provided code snippet, which outlines a basic banking operation involving an
> account balance withdrawal and an event notification. Enhance the code's structure, efficiency,
> throughput, maintainability, flexibility, consistency, fault tolerance, testability, dependency
> management, observability, auditability, portability, correctness, cost efficiency,
> interoperability and architecture — while preserving the existing business functionality.

Out of scope (per the brief): security, and the snippet is not required to compile or run.
